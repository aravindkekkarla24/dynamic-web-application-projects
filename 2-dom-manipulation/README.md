## Project Description

This project is a simple interactive light toggle application built using HTML, CSS, and JavaScript. It simulates a real-world light switch where users can turn the bulb on and off using buttons.

When the switch is turned ON, the bulb glows and the cat appears normal. When turned OFF, the bulb goes off and the cat's eyes glow in the dark. The button colors and status text also update dynamically based on the current state.

This project demonstrates basic DOM manipulation and event handling concepts in JavaScript.
