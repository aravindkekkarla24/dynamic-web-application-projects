## Project Description

This project is a Dynamic Recipe Page that displays recipe details such as title, image, and ingredients using JavaScript.

The content is generated dynamically using a JavaScript object (recipeObj). The image and list items are created and appended to the DOM dynamically.

Bootstrap is used to ensure the layout is responsive across different screen sizes.
