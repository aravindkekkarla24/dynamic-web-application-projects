## Project Description

This project is a Theme Switcher that allows users to toggle between light mode and dark mode.

When the user clicks the button, the background and text colors change dynamically by toggling a CSS class. The button text is also updated based on the current theme.

JavaScript is used to control the theme switching logic, while CSS handles the styling for both modes.
