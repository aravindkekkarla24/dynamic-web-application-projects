## Project Description

This is a simple counter application where the user can increase, decrease, and reset the counter value using buttons.

When the counter value changes:

* If the value is greater than 0, the color changes to green
* If the value is less than 0, the color changes to red
* If the value is 0, the color changes to black

The application demonstrates how JavaScript interacts with HTML elements and updates the UI dynamically based on user actions.
