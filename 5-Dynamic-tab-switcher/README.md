## Project Description  
This project is a Dynamic Tab Switcher built using HTML, CSS, and JavaScript.

It shows information about Varanasi in three sections: About, Time To Visit, and Attractions. When a user clicks on a tab, only the selected content is displayed while the other sections are hidden.

The functionality is implemented by adding and removing CSS classes dynamically using JavaScript.
