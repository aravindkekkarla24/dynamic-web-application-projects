## Project Description

This project is an Add to Cart Page where users can enter item names and add them to a list dynamically.

When the user clicks the Add button, the input value is taken and a new list item is created and appended to the cart. Empty inputs are validated to prevent invalid entries.

The application uses JavaScript for dynamic behavior and Bootstrap for basic layout and responsiveness.
