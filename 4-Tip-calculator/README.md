## What I Learned

* How to get input values using JavaScript
* Converting string input values into numbers using parseFloat()
* Performing calculations based on user input
* Updating DOM elements using textContent
* Basic form validation using isNaN()

## Project Description

This is a simple Tip Calculator web application. Users can enter the bill amount and tip percentage, and the application calculates the tip amount and total bill. It also includes input validation to ensure correct data is entered before performing calculations.
